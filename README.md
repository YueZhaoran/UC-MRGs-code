# Analysis code for migrasome-related genes in ulcerative colitis

## 1. Overview

This repository contains the analysis code for a study of ulcerative colitis (UC). The study integrates bulk transcriptome, single-cell transcriptome, GWAS summary statistics, and spatial transcriptome data to identify migrasome-related genes (MRGs), build a diagnostic model, and characterize the expression and regulatory mechanisms of key genes in key cell types and tissue space.

The code is organized by analysis step. Folder numbers correspond to the sections of the analysis report. Raw data, intermediate objects, and result figures are not included in this repository; see Section 6 for data access and file placement.

## 2. Data sources

| Data | Accession | Platform / type | Samples | Use |
|---|---|---|---|---|
| Training set | GSE87466 | GPL13158, Illumina HumanHT-12 array | 87 UC + 21 normal controls | Differential expression, machine-learning feature selection, GSEA, immune infiltration |
| Validation set | GSE75214 | GPL6244, Affymetrix Human Gene 1.0 ST array | 74 active UC + 11 normal controls | Key-gene expression validation, ROC analysis, external validation of the ANN model |
| Single-cell data | GSE214695 | 10x Genomics scRNA-seq | 6 UC + 6 healthy controls | Cell annotation, scPagwas, Scissor, key-cell identification, cell-cell communication, virtual knockout and overexpression |
| Spatial transcriptome data | GSE189184 | 10x Visium | 7 UC + 2 normal controls, 9 sections | Spatial localization of key genes, spatial cell-cell communication, spatial pseudotime |
| GWAS summary statistics | ieu-a-32 | OpenGWAS | 6,968 cases / 20,464 controls | scPagwas genetic association analysis |
| Migrasome-related genes | PMID:41921800 | Literature gene set | 35 MRGs | MRG scoring and Scissor phenotype definition |

Data sources:

- GEO: <https://www.ncbi.nlm.nih.gov/geo/>
- OpenGWAS: <https://gwas.mrcieu.ac.uk/>
- Migrasome-related genes: the 35 genes reported in PMID:41921800 are provided as `migrasome-genes.xls` and should be placed in the repository root.

## 4. Environment

- R 4.6.1 (2026-06-24), x86_64-w64-mingw32. Versions of the 83 R packages used in this project are listed in `env/R_environment.txt`.
- The scripts use `rstudioapi` to locate the directory of the current script. Run each script in RStudio. When using `Rscript`, call `setwd()` to the script directory first.
- GraphBAN drug prediction runs in Google Colab: `11GraphBAN/GraphBAN_Colab.ipynb`. Core dependency versions are listed in `env/requirements_graphban.txt`; the full environment snapshot is in `env/colab_pip_freeze.txt`.
- scFEA metabolic flux analysis uses Python. Dependencies are listed in `17scFEA/scFEA_src/requirements`, and the analysis is launched by `17scFEA/02_run_scfea.py`.
- CellOracle, SCENIC, and Palantir in the spatial transcriptome module run on a Linux server. The relevant scripts are `13spatial/09celloracle/06_celloracle_chain.sh`, `13spatial/09celloracle/10_scenic_chain.sh`, and `13spatial/10palantir/02_palantir_server.py`. Set `CONDA_ENV`, `BASE_GRN`, `RANKINGS`, `MOTIFS`, `CELLORACLE_PYTHON`, and related environment variables as described in the scripts before running.

## 7. Running the code

1. Open each script in RStudio. The script switches the working directory to its own folder. When running from the command line, call `setwd()` to the script folder first.
2. Run the modules in the order shown in Section 5, from 00 to 17. Within a module, follow the script file names or the method order in the report.
3. All relative paths are based on the module folder. Keep the directory structure unchanged.
4. Random seeds are set in the scripts, including `03Scissor/Scissor.R`, `05DEGs/VNN.R`, `06GSEA/06GSEA.R`, `09ssGSEA/GSA2.R`, `10scTenifoldKnk/scTenifoldKnk.R`, `13spatial/05deconv/06_spotlight.R`, and `16keygenescore/01_gene_set_scoring.R`.
5. CellOracle, SCENIC, Palantir, and scFEA include Python steps. Run them according to the environment variables and commands in the corresponding scripts. Dependencies and model files should be prepared as described in the scripts.
